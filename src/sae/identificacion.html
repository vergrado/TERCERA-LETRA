Identificarse

Tanto el adulto como el estudiante deben tener con un número identificador válido.

Los identificadores válidos son los siguientes:

  1. RUN (Rol Único Nacional): Cédula de identidad chilena.
  2. RUN de enrolamiento Art. 44: RUN de enrolamiento provisorio con el fin de acceder a servicios o trámites del Estado.
  3. IPE (Identificador Provisorio del Estudiante): Número único otorgado por el Ministerio de Educación a extranjeros menores de edad, que se encuentran en territorio nacional y con el fin único de realizar la postulación en el Sistema de Admisión Escolar.
  4. IPA (Identificador Provisorio del Apoderado): Número único entregado por el Ministerio de Educación a padres, abuelos, tutores legales o simples extranjeros, con el fin único de realizar la postulación en el Sistema de Admisión Escolar.
ESTUDIANTE APODERADO

Dependiendo de la situación, podrás solicitar para el postulante:

  • IPE (Identificador Provisorio Escolar).
  • RUN de enrolamiento Art. 44.

Una vez que el estudiante haya terminado su proceso de identificación, si no tienes un RUN o RUN de enrolamiento Art. 44 debes solicitar un IPA.
